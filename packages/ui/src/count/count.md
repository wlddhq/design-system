## When to use

- Beside titles, tabs and nav items: "Campaigns 28", "Active 17", "Approvals 3".

## Do

- Show the live number. Hide it when it's zero in navigation.

## Don't

- Don't write counts as sentences ("11 invoices awaiting review").
- Don't put a count in a coloured badge unless it needs action now.

## Edge cases

- Numbers get Indian grouping automatically: 1,240 · 12,40,000.

# @wldd/tailwind

A Tailwind v4 theme that holds only WLDD values. Tailwind's default palette, radii and shadows are removed, so off-brand classes like `bg-blue-500` don't compile.

```css
@import "tailwindcss";
@import "@wldd/tailwind";
```

Use the token names: `bg-surface`, `text-muted`, `border-line`, `rounded-card`, `text-green`.

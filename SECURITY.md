# Security

To report a vulnerability in `@wldd/ui`, `@wldd/tokens` or `@wldd/tailwind`, use GitHub's private
reporting: **Security › Report a vulnerability** on this repository. Please don't open a public issue.

Only the latest published version gets fixes.

Every version from 0.1.5 on is published from GitHub Actions with npm provenance. Check a version with
`npm audit signatures`, or look for "Provenance" on its npm page.
